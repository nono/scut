# scut v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `scut`, a Go CLI on the Shortcut REST API v4 with JSON output, plus its `SKILL.md`, to replace the Shortcut MCP.

**Architecture:** A cobra command tree (`internal/cli`) calls a client generated from the committed v4 spec (`internal/v4`). An HTTP doer (`internal/transport`) adds auth, retries and error mapping. Name-to-ID lookups go through a TTL file cache (`internal/resolve`, `internal/cache`). Every error becomes one JSON object on stderr and an exit code (`internal/exit`).

**Tech Stack:** Go 1.27 and oapi-codegen 2.8.2, both pinned in `mise.toml`. `github.com/spf13/cobra`. `github.com/BurntSushi/toml`. `github.com/zalando/go-keyring`. `github.com/google/uuid`. Prism (`npx @stoplight/prism-cli@5`) for contract tests.

**Spec:** `docs/design/2026-11-04-scut-design.md` (approved). Requirements: the requirements page (private) (version 8).

## Global Constraints

- Module path: `github.com/nono/scut`. Binary: `scut`. Go 1.27.
- API base: `https://api.app.shortcut.com/api/v4/{workspace-slug}/`. `whoami` is `/api/v4/whoami`, with no slug.
- Token form: `sct_{scopes}_{workspace-slug}_{secret}`. The slug comes from the token.
- Attachment download uses the `Shortcut-Token: <token>` header. Never `Authorization: Bearer`, never `?token=`.
- JSON on stdout by default. `--human` or `SCUT_OUTPUT=human` gives text. Errors: one JSON object on stderr with `error`, `status`, `api`, `suggestion`, `valid`.
- Exit codes: 0 ok, 1 other, 2 usage, 3 not found, 4 auth, 5 unavailable, 130 cancelled.
- Retries: 429, 502, 503, 504, connect failure. 4 tries, 20 s total at most. Use `Retry-After`.
- Default page size 25. `--limit all` pages to the end. Stop when the cursor repeats or after 100 pages.
- Name match: exact and case-sensitive. On a miss, refresh the cache once, then exit 3 with `valid`.
- Cache: `$XDG_CACHE_HOME/scut/<workspace>/`, TTL 1 hour.
- Config: user `$XDG_CONFIG_HOME/scut/config.toml`, repo `.scut.toml` (current dir up to git root). Precedence: flag > env (`SCUT_*`) > repo file > user file > default.
- Token: `--token-file` > `SCUT_TOKEN` > `token_file` in user file > OS keyring. A repo file with `token` or `token_file` is an error. Trim whitespace.
- The token never appears in stdout, stderr, a URL or a log line.
- `--help` and `usage` need no token.
- Never prompt unless `--human` and stdin is a terminal.
- No shell script over 100 lines. No special case for test inputs.
- Commit messages: a short description that starts with a capital letter, no final period, no Conventional Commits prefix. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Release: linux amd64 only.
- Delete this plan file before merge.

## Review Focus

1. **An HTML or empty 5xx body** (shortcut-cli #4): exit 5 with no JSON parse error. Test: Task 3 `TestDoerNonJSON5xx`.
2. **A mock or API that returns the same cursor forever** (shortcut-cli PR 395): paging stops. Test: Task 3 `TestPagerRepeatCursor`.
3. **A create that times out but was done on the server**: no duplicate story. Test: Task 10 `TestCreateRetryFindsExisting`.
4. **An attachment URL that returns 400 or a short body**: no file stays in `--out`. Test: Task 12 `TestFilesErrorLeavesNoFile`.
5. **A token with a trailing newline, or a token in `.scut.toml`**: the first works, the second is refused. Test: Task 2 `TestTokenTrim`, `TestRepoFileTokenRefused`.
